# Auto Edge Finish

Autodesk Fusion add-in by Spark Robotic: fillet/chamfer a whole body by edge group, with presets, per-group control and automatic fallback.

## Install

1. Clone or download this repo into your Fusion add-ins folder:
   - Windows: `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\AutoEdgeFinish`
   - macOS: `~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/AutoEdgeFinish`
2. In Fusion, open **Utilities > Add-Ins** (Shift+S), select **AutoEdgeFinish** and click **Run**.
